# fnAudio 0.1.172 发布说明

发布日期：2026-08-07

## 软件介绍

fnAudio 是一款运行在 fnOS NAS 上的本地音乐库与多目标播放器。它把音乐整理、网页播放、本机音频输出、DLNA 设备控制和移动端播放整合在一起，适合把 NAS 作为家庭音乐中心使用。

fnAudio 不只是一个文件列表播放器：它会建立可搜索、可排序的音乐库，并统一管理播放队列、收藏、播放列表、歌词、封面和播放状态。

## 基本功能

### 音乐库管理

- 扫描和索引 NAS 音乐目录，支持按歌曲、专辑、歌手、作曲者、文件夹等方式浏览。
- 支持标签和文件名元数据展示，并提供搜索、排序、分页和专辑曲目序号。
- 支持收藏歌曲、自建播放列表和当前播放队列。
- 支持封面、歌词和后台元数据补全；没有封面时使用统一的音乐符号占位。
- 支持 DSD、CUE 等音乐场景的识别与播放链路处理。

### 播放与队列

- 浏览器直接播放，支持当前歌曲优先缓存，减少开始播放等待。
- 支持从当前歌曲开始播放当前页面或当前上下文中的全部歌曲。
- 支持加入当前队列、插播、循环、随机、上一首/下一首和播放进度控制。
- 当前播放队列可以直接定位到正在播放的歌曲，并显示“正在播放”标识。
- 支持本机 MPD/ALSA/USB DAC 输出，以及远程 DLNA 播放设备推送。

### DLNA 与设备互操作

- 可作为 DLNA MediaServer 提供音乐内容浏览。
- 可作为 DLNA MediaRenderer 接收局域网控制。
- 可作为 Control Point 将歌曲推送到兼容的电视、音箱和播放器。
- 支持播放设备选择、音量和播放状态同步等常用控制。

### Android 混合客户端

- 原生登录页支持 NAS 地址、端口、HTTP/HTTPS 和自签名证书选项。
- 支持保存密码和多个 NAS 连接历史，可选择、编辑、删除和新增连接。
- 登录后直接进入 fnAudio，不经过 fnOS 桌面。
- WebView 负责界面，Android Media3 原生服务负责播放队列、通知栏、媒体按键和后台播放。
- 原生网络桥接负责认证 API 和媒体请求，降低 WebView 在后台或息屏时中断播放的概率。

### PC 与移动端交互

- PC 端支持鼠标右键、双击播放和多选操作。
- 移动端支持歌曲长按菜单，避免触摸滚动与普通点击互相干扰。
- PC 和移动端使用独立菜单规则，针对不同设备的操作习惯分别优化。
- 歌曲详情页、歌词页、队列页和播放控制栏保持联动。

## 0.1.172 本版亮点

- PC 端歌曲右键菜单取消“播放”和“插播所选项目”，减少与普通点击及播放控制的重复入口。
- 文件夹、专辑等分组右键菜单同步移除上述两项，保持 PC 菜单结构一致。
- 移动端长按菜单继续保留：从当前开始播放所有歌曲、加入当前队列、收藏歌曲、加入播放列表。
- 歌曲操作对话框仍保留完整歌曲操作，不影响播放、插播和歌曲信息等功能。
- 修复“打开包含的文件夹”误把完整音频路径当作文件打开的问题。现在只传递歌曲父目录，例如：

  ```text
  /vol1/1000/123/
  ```

  而不是把下面的完整路径交给文件管理入口：

  ```text
  /vol1/1000/123/陈晓枫 - 2025 年的新年.mp3
  ```

- Android 客户端版本号同步为 `0.1.172`，`versionCode` 更新为 `172`。

## 兼容性与注意事项

- fnOS FPK 平台：`x86`。
- fnOS 服务端口：默认 `18080`。
- Android 客户端最低支持 Android 8.0 / API 26。
- Android APK 为 Debug 构建，适合测试和个人安装，不是正式签名发布包。
- 本轮未连接真实 fnOS 或 Android 设备；发布前建议在目标设备上复验右键菜单、文件夹跳转、覆盖升级和 Android 登录/播放流程。
- fnOS 公开的 `openFileManager` 接口已确认支持打开目录，但尚未确认存在“打开目录并自动选中文件”的公开参数。因此本版保证进入正确父目录，不对自动高亮文件作承诺。
