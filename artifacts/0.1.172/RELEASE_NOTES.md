# fnAudio 0.1.172

发布日期：2026-08-07

## 版本摘要

本版主要优化 PC 端右键菜单和 fnOS 文件管理跳转行为，同时继续保持移动端长按菜单与 PC 端交互独立。

## 主要更新

- PC 端歌曲右键菜单取消“播放”和“插播所选项目”。
- PC 端文件夹、专辑等分组右键菜单同步取消“播放”和“插播所选项目”。
- 移动端长按歌曲菜单保持以下四项：
  - 从当前开始播放所有歌曲
  - 加入当前队列
  - 收藏歌曲
  - 加入播放列表
- 歌曲操作对话框继续保留完整歌曲操作，不受 PC 右键菜单精简影响。
- 修复“打开包含的文件夹”把完整歌曲路径传给 fnOS 宿主的问题。现在只传递歌曲父目录，例如：

  ```text
  /vol1/1000/123/
  ```

  不再把下面这种完整路径当作要直接打开的音频文件：

  ```text
  /vol1/1000/123/陈晓枫 - 2025 年的新年.mp3
  ```

- Android 客户端版本号同步为 `0.1.172`，`versionCode` 更新为 `172`。

## 兼容性与注意事项

- fnOS FPK 平台：`x86`。
- fnOS 服务端口：默认 `18080`。
- Android 客户端最低支持 Android 8.0 / API 26。
- Android APK 为 Debug 构建，适合测试和个人安装，不是正式签名发布包。
- 本轮未连接真实 fnOS 或 Android 设备；发布前建议在目标设备上复验右键菜单、文件夹跳转、覆盖升级和 Android 登录/播放流程。
- fnOS 公开的 `openFileManager` 接口已确认支持打开目录，但尚未确认存在“打开目录并自动选中文件”的公开参数。因此本版保证进入正确父目录，不对自动高亮文件作承诺。
