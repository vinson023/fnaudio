# fnAudio 0.2.100 更新说明

发布日期：2026 年 10 月 22 日

fnAudio 0.2.100 是服务端、fnOS FPK 和 Android 客户端同步发布版本。该版本重点修复 DSD 规格识别、访问码登录、曲库扫描与元数据处理问题，并整理了发布仓库中的过期审查记录。

## 主要更新

### DSD 音质识别

- 修复 DSD128、DSD256 等文件被统一显示为 2.8MHz 的问题。
- DSF 读取文件原生采样频率，DFF 与 DSF 均使用真实频率覆盖不可靠的通用探测结果。
- 统一按以下格式显示 DSD 规格：
  - DSD64：2.8MHz
  - DSD128：5.6MHz
  - DSD256：11.3MHz
  - DSD512：22.6MHz
- 旧版本索引会通过元数据版本升级自动重建，避免继续使用错误的 DSD 频率缓存。

### 曲库扫描与列表体验

- 改善大曲库分页、文件夹查询和列表增量更新，减少重复请求与整页重绘。
- 文件夹分类和子文件夹导航继续使用优化后的快速路径，分类切换后滚动位置自动回到顶部。
- 元数据、封面和播放状态更新采用比较后写入，减少列表闪烁和无效 DOM 更新。
- 无封面歌曲显示稳定的占位图，不再出现破图闪烁。

### 元数据与封面

- 支持自动匹配、指定数据源搜索和手动输入关键词搜索。
- 候选结果按数据源保留，用户可以在补全页面选择具体数据源和候选信息。
- 修复候选查询失败、空结果、迟到响应覆盖当前页面等问题。
- WAV 确认候选后，文字 Tag 写回与封面写入分别进入持久队列。
- WAV 封面写入使用 ID3/APIC 数据块，音频载荷保持不变。
- 元数据补全后的可见列表会增量刷新，不再强制整页重载。

### Android 客户端

- Android 客户端版本同步为 `0.2.100`，`versionCode=365`。
- 修复访问码登录后的 Cookie、Authorization 和同源 API 请求传递。
- 修复登录成功后读取歌曲列表失败、响应体不完整和设置回显不一致的问题。
- 登录页增加密码和访问码的显示/隐藏按钮。
- 保持 WebView 界面与服务端当前版本同步，原生媒体服务继续负责队列、通知和远程播放控制。

### fnOS 与发布整理

- FPK、服务端源码和 Android 客户端统一使用 `0.2.100`。
- 发布包继续使用正式应用身份 `fnaudio`，开发者和发布者为 `vinson023`。
- 删除 36 份已停用的逐轮“修改审查对照”文档；Git 历史仍然保留，便于追溯。
- 发布候选内容排除了本机密码、访问码、部署脚本、设备日志、SDK 和 Gradle 缓存。
