## 一、登录页不再问证书的事

**以前**：登录页有「允许自签名证书」勾选框。不勾的话，遇到自签证书就报「HTTPS 证书校验失败」；
勾了又经常不管用——因为它只对「手填域名 + 自签证书」这一种情况生效，FN ID 登录、手填 IP、中继这几条路
根本不看这个开关。

**现在**：勾选框去掉了，规则改成和飞牛官方 App 一致——

- 任何 HTTPS 设备的证书都直接接受，不再让用户决定
- 第一次连上时把证书指纹记下来
- **以后这张证书一旦变了，立刻拒绝并提示**，不会悄悄换成别人的

所以安全性没有丢：防的不是「第一次连的设备是不是自签」，而是「之后连的还是不是同一台」。

## 二、升级注意

- 安卓端：覆盖安装即可。以前勾过的档案照常能用，那个勾选值不再影响行为。
- 服务端：本版无改动，FPK 只是随版本号重出，可不升级。
