# fnAudio 更新说明（0.2.151 → 0.2.157）

这一段落修的是**用起来会卡住的几处**：WMA 播不了、开了转码点下一首要等、手机上开了转码电脑上还是关的、点了歌只能播一首、局域网里谁都能改你的播放。下面按"你遇到什么"写，不按代码写。

---

## 一、播放（0.2.157）

**1. WMA 等格式不用再手动开转码了**

以前 WMA 必须打开「MP3 转码」才能播——因为浏览器和安卓播放器都**没有 WMA 解码器**，直接给原文件只会失败。现在服务端按格式自己判断：

| 格式 | 行为 |
|---|---|
| MP3 / FLAC / M4A / AAC / OGG / OPUS / WAV | 原文件直出，不转码 |
| **WMA / AIFF / WV / MPC** | **自动转 MP3**，不用你设任何开关 |
| APE / DSD(DSF·DFF) / CUE 分轨 | 各自的无损通道，保持原样 |

需要说明的是：WMA **不可能"原文件播放"**，这是平台限制（两端都没有解码器），自动转码是唯一可行路径。

**2. 开了转码，点「下一首」不再等半天**

原因是缓存没命中时要等转码器起第一帧。现在当前这首一开始出声，就会**提前把下一首转好**，按下一首基本秒开。

**3. 点一首歌就能顺下去播**

以前必须先用「从该处播放全部」把列表塞进队列，否则点一首就只播这一首、下一首没反应。现在**点哪首就从哪首开始按顺序往下播**；随机 100 首同理，那 100 首就是队列。在播放队列视图里点，仍以队列本身为准。

**4. 转码开关跨端同步**

「MP3 转码」以前只存在各自浏览器里，手机开了电脑上还是「关」。现在这个设置存在服务端，**一处改动，其它端跟着变**。

---

## 二、登录（0.2.152）

**不再替你勾选 HTTPS**

登录页的「HTTPS 安全访问」以前是强制勾上的，现在按你的选择来。如果设备只支持一种协议，会提示并把勾选状态回填，不会默默改掉你的设置。

---

## 三、安全（0.2.153 → 0.2.155）

**局域网直连 `IP:端口` 已经关闭**

这个端口在飞牛网关之外，请求**不经过任何身份校验**。以前为了能用而放开，等于同网段任何人都能看你的曲库、控制播放、改收藏。现在只放行两条路：

- **飞牛应用中心 / `NAS:5666` 入口**——正常使用，功能完全不变
- **DLNA 投播**——电视、音箱直接取流；UPnP 协议本身没有鉴权，封掉就投不出声，所以保留

浏览器直接访问 `http://内网IP:端口` 会看到一张说明页，告诉你怎么进来。

---

## 四、界面（0.2.151 / 0.2.154 / 0.2.156）

- **数据维护整理成两步**：三颗并列的按钮改成「步骤 1 清理失效收藏 → 步骤 2 重建曲目标识并迁移收藏」，不可逆的「清空」单独隔进虚线危险区——这两件事本来就有先后顺序，之前看不出来。
- **关于页显示版本号**：数字取自正在运行的服务端，升级后不会还显示旧版本。
- **安卓图标修正**：修掉自适应图标被圆形遮罩切边的问题；图标里的音符也缩小一圈，四个圆角不再挤在一起。

---

## 升级步骤

1. **服务端**：应用中心更新 `fnaudio-0.2.157-fnpack.fpk`
2. **手机**：覆盖安装 `fnaudio-android-0.2.157-release.apk`（与旧包同签名，可直接覆盖）
3. 打开 **设置 → 高级 → 数据维护**，按顺序点一次「① 清理失效收藏」→「② 重建曲目标识并迁移收藏」
4. 桌面图标没变的话，**重启手机**（启动器缓存不会自动刷新）

> 直连地址已不可用，请从飞牛应用中心打开；投音到音箱/电视不受影响。

## 已知限制

- **WMA 只能转码播放**：浏览器与安卓都没有 WMA 解码器，这是平台限制。
- **直连端口不可用**：为安全关闭；DLNA 投播不受影响。
- **重装前丢失的收藏无法恢复**：旧标识是单向哈希，反推不出是哪首歌，只能用「清理失效收藏」删掉。
