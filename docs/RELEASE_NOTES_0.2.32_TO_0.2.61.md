# fnAudio 0.2.32 - 0.2.61 更新说明

## 范围说明

本文根据当前仓库 `main` 分支、Git 提交历史和 `CHANGELOG_AI.md` 整理，终点为正式版 **0.2.61**。

仓库中并非每个小版本都有独立 Git tag：现有正式版本 tag 从 `v0.2.35` 开始，0.2.33 和 0.2.34 的发布产物及变更记录仍保留在仓库中。0.2.52 - 0.2.60 没有在当前发布记录中形成独立的用户版说明，相关改动以 0.2.61 当前代码为准。

## 主要更新

### 1. 曲库扫描与大曲库性能

- 重构曲库分页、文件夹、分组和搜索查询路径，减少全库扫描、Python 侧过滤和重复排序。
- 为 SQLite 查询、内存查询和文件夹范围查询统一语义，修复容器目录精确匹配导致的空结果和慢回退。
- 增加分页缓存、引用曲目补水、FTS5 搜索和大曲库基准验证，改善数万首及十万首规模曲库的首屏和分页响应。
- 修复 inotify 监听数量不足导致监听启动失败、扫描永久退回 polling、扫描反复执行的问题。
- 扫描期间的数据库写入改为有界、可重试的事务路径，降低 `database is locked` 和扫描反复重启。
- 识别并忽略 fnAudio 自己生成的 Tag 写回临时文件，避免自写回触发无意义的再次扫描。
- 扫描状态、已收录数量和索引建立状态的显示文案更加准确，避免把冻结计数误显示为实时进度。

### 2. 文件夹分类与导航响应

- 修复文件夹分类和子文件夹点击出现“慢半拍”的多个原因：
  - 减少单根音乐库进入文件夹分类时的串行根目录请求。
  - 复用已经获取的单根曲库配置，直接进入文件夹和曲目查询。
  - 对文件夹入口、悬停和按下动作增加有界预取，减少点击后才开始发请求的等待。
  - 导航期间暂停封面、元数据和后台状态轮询，释放浏览器与 fnOS CGI 网关的连接。
  - 不再在加载期吞掉文件夹、面包屑、分页和分组导航事件。
  - 取消上一页仍在飞行的封面请求，避免旧页面请求阻塞新页面。
- 分类切换后滚动位置恢复到顶部。
- 文件夹行进入行为调整为双击进入，降低误触概率。

### 3. 播放、MPD 与 USB DAC

- 修复 MPD 端口自连抢占导致 MPD 无法重新绑定、播放持续失败的问题。
- 修复 MPD 将自身正在使用的端口误判为旧实例并杀掉，避免每次播放、停止和切歌都重启 MPD。
- 增加 MPD 暖启动路径，在配置、进程握手和优先级均未变化时复用现有实例。
- 优化 ALSA/USB DAC 设备枚举，跳过无关声卡的昂贵信息读取。
- 播放状态查询使用轻量状态快照，减少重复的完整 MPD 查询。
- 修复 MPD 队列中的旧 song id 被误判为“曲库没有这首歌”的问题。
- 播放失败后可清理旧队列身份并重建队列，避免持续返回 `No such song`。
- 修复 MPD 索引目录持久化位置错误、升级后索引丢失和全量重建的问题。
- 增加索引追赶和单飞保护：播放遇到未收录曲目时请求定向更新或全库收敛，避免重复启动多个更新任务。
- DSD/DSF 播放失败时显示可执行的索引状态和等待原因，不再把所有失败归因于 DAC 或解码器。
- 减少 DAC 播放控制和状态反馈延迟；真机取证中，播放控制平均耗时曾由约 1.9 秒降至约 0.25 秒。

### 4. 元数据、封面与歌词

- 元数据请求增加有限并发、去重、取消和短 TTL 复用，减少同一曲目重复请求。
- provider 暂时不可用、返回空结果或 worker 恢复期间，继续显示本地 Tag、文件名、已有封面和歌词，避免界面短暂变空。
- 修复 provider 失败或无匹配后永久占用预取去重键的问题，使后续可再次恢复。
- 增加显式重试路径，用户主动重试时可清除短时 provider 冷却。
- 统一 artwork ID 校验、缓存和相对 URL 投影，清理异常封面引用，避免生成无效图片地址。
- 封面加载改为有界调度、增量 hydration 和失败重试，减少分页、播放状态更新造成的重复加载和闪烁。
- 修复无封面歌曲显示破图的问题，改为稳定的统一占位显示。
- 修复列表行在元数据回投时被无条件替换，减少封面闪烁并保留已经加载的图片节点。
- 修复元数据队列和可见页面投影更新过于频繁的问题，降低后台轮询对导航和播放的影响。

### 5. UI 稳定性与响应体验

- 首屏从快照到权威曲库响应采用稳定的 keyed reconciliation，尽量复用已有行节点和封面。
- 对不改变用户可见状态的后台响应跳过整页重绘，改为局部刷新播放行、导航和控制状态。
- 文本和播放状态写入增加比较后更新，减少无变化 DOM 写入。
- 播放停止、切歌和恢复空状态时统一清理传输行、进度、按钮状态和远程 UI 状态。
- 无当前歌曲、扫描中和状态未知等场景的显示更加明确，避免残留上一首歌的信息。

### 6. fnOS 发布与安装

- 正式版应用账号统一为 `fnaudio`，开发者和发布者统一为 `vinson023`。
- 正式版安装目标使用系统分区并支持 root 安装模型。
- Beta 与正式版保持独立身份、端口、数据目录和安装目标，避免测试版与正式版混装。
- 发布打包增加版本载体、manifest 身份、安装目标、FPK 内容和 SHA-256 校验。
- 增加发布证据索引、源码清单和恢复校验工具，便于确认 FPK 与源码对应关系。
- 版本号同步覆盖 fnOS 包、服务端、Android 客户端、README 和发布文档，避免安装后仍显示旧版本。
- 当前正式发布为 **0.2.61**，GitHub Release 与 `main` 分支均对应该版本。

### 7. Android 客户端

- 保持 Android 客户端版本号与 fnOS 正式版同步推进。
- 修复 WebView 内联资源和元数据请求加载路径的同步问题。
- 保留 Debug 签名测试路径与正式签名校验边界；未配置正式签名材料时不会误生成正式签名包。
- Android 端继续复用曲库、元数据、播放状态和封面相关协议的兼容修复。

## 重要兼容与限制说明

- 0.2.32 到 0.2.34 的历史发布证据并不完整，尤其 0.2.33 的源码 provenance 无法从现存材料完全恢复；本文只列出当前仓库能够证实的变化，不补写无法验证的历史细节。
- USB DAC、DSD、fnOS 网关和 Android 多机型的最终体验仍取决于实际设备、系统版本、驱动和曲库状态。
- 0.2.61 是当前主线正式发布版本；升级时应使用对应版本的 FPK，不要把 Beta 包当作正式版升级包。
