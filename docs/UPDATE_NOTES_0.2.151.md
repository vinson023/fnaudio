# fnAudio 0.2.151 更新说明

版本 `0.2.151`，`versionCode` 409。本版是 0.2.150 的补充修复，只改界面与图标，不涉及数据。

> 已经发过 0.2.150 说明的话，把下面三节追加到原帖即可。

---

## 一、数据维护的三个按钮现在一样大

设置 → 高级 → 数据维护里，「清理失效收藏」「清空收藏与播放列表」「重建曲目标识并迁移收藏」原来宽窄不一：前两个挤在一行、第三个换行后只剩文字那么宽，看着像三种规格的控件。

现在三个按钮等宽等高：手机上一列排开，屏幕够宽时自动并排。

## 二、关于里能看到版本号了

设置 → 高级 → 关于，新增「版本」一行。

这个数字来自**正在运行的服务端**，不是写死在页面里的——升级之后它会自己变，不会出现「装完了却显示旧版本」这种误判。

## 三、手机桌面图标和 NAS 应用中心统一了

原来的安卓启动图标是「蓝色圆角方块 + 白色音符」，而 fnOS 应用中心里是「白色底 + 蓝色音符」——同一个标识正反两种配色，摆在一起像两个不同的应用。

现在两端共用同一套：白底、蓝色双音符。手机上的圆角/圆形外框由启动器决定，无法强制成方形，但底色和图形已经完全一致。

> 图标缓存：部分启动器升级后仍显示旧图标，重启手机或更换一次桌面布局即可刷新。
