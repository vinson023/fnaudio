# fnAudio 更新说明：0.2.147 → 0.2.148

| 版本 | versionCode | 主要内容 |
|---|---|---|
| 0.2.148 | 406 | 安卓端用 FN ID 从公网登录；撤掉临时的网页登录入口 |

---

## 一、安卓端：FN ID 从公网能登录了

**以前**：填域名能登录，填 FN ID 就报「HTTPS 证书校验失败」；切「公网连接」或「速度优先」更是必定失败。

原因是叠加的一串问题，逐个查出来修掉的：

| 现象 | 真正的原因 |
|---|---|
| 明明勾了「允许自签名证书」还报证书失败 | 恢复连接时重建档案，把「允许自签名」这个勾选抹掉了 |
| 用公网 IP 走 HTTPS 永远失败 | 公共机构不给 IP 签证书，用地址做主机名校验在原理上就不可能通过 |
| 刚登录成功、主界面立刻报证书失败 | 主界面恢复连接时没带上档案自己的 HTTPS 选择，整段连接被降级成 `http`，再被 NAS 302 到 `https`，那条跳转没有信任策略 |
| 登录闪退 | 令牌失效回退密码时，在主线程关闭连接池，进程被系统杀掉 |
| 登录成功但曲库空、报「响应体不完整」 | 会话跑在 `http://…:5666` 上，每个请求都先明文发一次再被 302，重定向后认证头丢失 |

**现在**：FN ID + 公网连接（或速度优先）可以直接进入曲库并播放。已在 **三星 S9+** 上实测：
曲库完整加载、封面正常、点播放后进度走动、`MP3 · 原文件播放`。

> 前提：外网直连需要手机有 **IPv6**（这台 NAS 的公网 IPv4 端口没有映射）。手机没有 IPv6 时会自动改用「中继」，
> 速度略慢但可用。

## 二、撤掉「用飞牛网页登录」入口

0.2.147 中途加过一个「用飞牛网页登录（推荐）」按钮，用网页打开飞牛官方登录页来绕开证书问题。
既然原生路径已经修好，这个入口就是多余的，已连同其页面一起移除——登录页恢复成原来的样子：
填地址或 FN ID，输账号密码，点「登录」。

## 三、升级注意

- 安卓端：覆盖安装即可，**不需要重新登录**（档案里的 HTTPS 与自签名选择会被保留并自动纠正）。
- 服务端：本版没有改动 fnOS 侧的运行逻辑，FPK 只是随版本号重出，可不升级。
