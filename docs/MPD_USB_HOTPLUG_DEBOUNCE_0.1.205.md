# 0.1.205 USB DAC 热插拔监控改进

## 变更

`MpdService` 的 USB DAC 监控此前在一次 ALSA 枚举缺失时就停止 MPD，在一次重新出现时就立即恢复。USB 音频设备重枚举期间可能连续出现短暂空窗，这会把正常热插拔过程误判为永久断开。

0.1.205 增加连续样本确认状态机：

- 默认连续 2 次（约 4 秒）未发现选定 DAC，才进入 disconnected 状态并停止 MPD。
- 默认连续 2 次（约 4 秒）重新发现选定 DAC，才进入 reconnected 状态并触发队列/播放恢复。
- 反向样本会清零另一方向计数，避免单次抖动触发状态切换。
- 可通过 `mpd_device_presence_samples` 配置，范围限制为 1–5。

## 自动化验证

- 覆盖首次缺失不触发、连续缺失触发、连续恢复触发以及计数器复位。
- 本地 Python unittest：121 项全部通过。
