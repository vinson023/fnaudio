# fnAudio 0.1.21

## CUE 自动切歌修复

- 修复 MPD 播放整轨 CUE 时，段落播放到结束后自动进入下一首的路径解析。
- 自动切歌与手动上一曲、下一曲使用同一套完整曲目解析，确保下一段携带实际文件路径、CUE 起止时间和格式信息。
- 输出插件返回失败时不再把自动切歌误判为成功，避免界面状态和实际播放状态脱节。
