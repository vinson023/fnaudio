# fnAudio 0.1.22

## 私有 MPD 停止可靠性

- 增强应用停止脚本：除读取私有 MPD 的 PID 文件外，还会扫描明确使用 fnAudio 私有 `mpd.conf` 的遗留进程。
- 当 PID 文件丢失、过期，或服务异常退出时，停止应用仍会停止 fnAudio 自己启动的 MPD，避免设备继续播放或下次启动形成重复实例。
- 匹配条件限定为 `mpd`、`fnaudio` 和 `mpd.conf` 同时存在的进程命令行，不会影响系统或其他应用的 MPD 实例。

## 验证

- 停止脚本 Bash 语法校验通过。
- 在内网测试机执行真实停止/启动回归：停止后 MPD 与服务端口均已退出；启动后健康检查恢复，并且仅存在一个 fnAudio 私有 MPD 实例。
