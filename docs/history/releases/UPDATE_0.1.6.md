# fnAudio 0.1.6 更新说明

## 播放设备切换

- 切换播放目标时，播放核心会先关闭旧输出插件。
- 切换离开 UPnP/DLNA 设备时会发送 `Stop`，避免旧设备继续播放。
- 切换离开本机 ALSA、USB DAC 时会停止当前本地输出进程。
- 浏览器切换到远端设备时会同时停止浏览器本地音频，避免两个设备同时发声。

## MPD 私有实例与进程监督器

- 增加应用私有 MPD 服务管理器。
- MPD 使用应用自己的数据目录、数据库、状态、播放列表和日志，不依赖系统全局 MPD 配置。
- MPD 采用前台模式运行，由 fnAudio 进程监督器负责启动、停止、异常退出后的自动重启和状态报告。
- MPD 启动后会等待本地端口真正可连接，再向前端报告可用，减少刚启动时的连接失败。
- 未捆绑或未找到 MPD 可执行文件时，MPD 目标显示为不可用，不影响浏览器、DLNA 和 ALSA 输出。

## 兼容性说明

- 当前版本只接入 MPD 输出插件和私有实例管理边界，MPD 可执行文件仍需后续随应用集成或由系统提供。
- 多音乐目录在 MPD 配置中暂时使用首个目录，现有 fnAudio 音乐库仍支持多路径扫描。
