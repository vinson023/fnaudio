# fnAudio 阶段四：服务器端播放状态与媒体管理

## 目标

将收藏、播放列表和播放会话从浏览器本地存储迁移到 NAS 应用数据目录，使浏览器、移动端 WebView 和 DLNA Renderer 使用同一份状态。

## 任务

- [x] 建立独立 SQLite 状态数据库及播放会话、收藏、播放列表数据表。
- [x] 提供状态读取与保存 API；旧浏览器数据的首次迁移将在前端接入时处理。
- [x] 收藏和播放列表改为以 NAS 状态为准，并迁移旧浏览器数据。
- [x] 前端队列操作改为由 Playback Core 确认后回写界面，避免多窗口队列互相覆盖。
- [x] 保存队列、当前曲目、循环、随机和播放目标；应用重启后恢复但不自动播放。
- [x] 为状态写入加节流和冲突处理，避免多窗口互相覆盖。
- [x] 完成浏览器与 DLNA Renderer 的连续会话验证：队列、收藏和播放状态可跨页面同步；覆盖 Play/Stop 竞态、Pause/Play 恢复及 SetNextAVTransportURI/Next。
- [ ] 在真实飞牛移动端 WebView 验证前后台切换、收藏/队列同步和恢复后的播放状态。
