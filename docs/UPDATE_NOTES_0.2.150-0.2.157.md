# fnAudio 更新说明（0.2.150 → 0.2.157）

这八个版本修的都是"实际用起来卡住"的地方：外网登不上、跟着几天就失效、WMA 播不了、点了下一首没反应、收藏越积越多、局域网里谁都能改你的播放。下面按"你遇到什么"来写，不按代码写。

---

## 一、播放

**1. WMA 等格式不用再手动开转码了**
以前 WMA 必须打开"MP3 转码"才能播——因为浏览器和安卓播放器都**没有 WMA 解码器**，直接给原文件只会失败。现在服务端按格式自己判断：

| 格式 | 行为 |
|---|---|
| MP3 / FLAC / M4A / AAC / OGG / OPUS / WAV | 原文件直出，不转码 |
| **WMA / AIFF / WV / MPC** | **自动转 MP3**，不需要你设任何开关 |
| APE / DSD(DSF·DFF) / CUE 分轨 | 各自的无损通道，保持原样 |

顺带说明：WMA **不可能"原文件播放"**，这是平台限制，不是没做。

**2. 开了转码，点"下一首"不再等半天**
原因是缓存没命中时要等转码器起第一帧。现在当前这首一开始出声，就会**提前把下一首转好**，按下一首基本都是秒开。

**3. 点一首歌就能顺下去播**
以前必须先用"从该处播放全部"把列表塞进队列，否则点一首就只播这一首、下一首没反应。现在**点哪首就从哪首开始，按顺序往下播**——随机 100 首也是同样，那 100 首就是队列。在播放队列视图里点，仍然以队列本身为准。

**4. "随机 100 首"真的给 100 首**
以前实际只返回一页：手机 60 首、桌面 96 首，所以你会觉得"只随机了五十多首"，而且队列跟着截断、到队尾点下一首没反应——这两个是同一个问题。

## 二、登录

**1. 外网 FN ID 登录失败：「访问码验证成功但未取得会话 Cookie」**
外网入口会先跳一次 HTTPS，会话 Cookie 设在那次跳转的响应上，旧版本只读了最后一跳。现在逐跳读取，外网登录稳定了。

**2. 用几天就突然要重新登录**
fnOS 的登录令牌会过期（短的几分钟、长的几周）。以前两者都过期后直接判失败；现在会自动用你**保存的密码**续登，过程无感。
> 前提是登录时勾了「记住密码」，没勾仍会要求重输——这是安全设计。

**3. 登录失败可以直接复制诊断**
失败弹窗多了「复制诊断」，点一下复制一段文字：连的哪个地址、走的哪条路由、卡在哪一步、有没有拿到会话 Cookie、令牌在不在。**不含密码、令牌、访问码**，可以放心贴出来。

**4. 不再替你勾选 HTTPS**
登录页那个「HTTPS 安全访问」复选框以前是强制勾上的，现在按你的选择来；如果设备只支持一种协议，会提示并回填。

## 三、收藏与数据维护

**1. 收藏越积越多**
根因：每首歌的"身份证"是用**文件路径**算的。重装系统、换硬盘、改挂载路径之后整库标识全变，旧收藏就变成指向不存在文件的记录——计数还在涨、列表里看不到、同一首歌再收藏又并排多一条。

现在改成按**文件内容**生成标识：改名、挪目录、换硬盘都不再影响收藏。

**2. 设置 → 高级 → 数据维护（两步）**

| 步骤 | 做什么 |
|---|---|
| ① 清理失效收藏 | 只删曲库里已不存在的条目，能播放的收藏一条不碰（索引为空时拒绝执行，避免误删） |
| ② 重建曲目标识并迁移收藏 | 把收藏、播放列表、播放队列统一换成新标识；**执行前自动备份两个数据库**，完成后显示迁移了多少条 |

下面单独隔开的「清空收藏与播放列表」是不可逆的那颗，曲库还在但想从头来时用。

**3. 一个必须说清的边界**
重装 **之前**丢失的那批收藏救不回来——旧标识是单向哈希，反推不出是哪首歌，只能清理。这一版是为了以后不再发生。

## 四、安全

**局域网直连 `IP:端口` 已经关闭。**

这个端口在飞牛网关之外，请求**不经过任何身份校验**。以前为了能用，同网段任何人都能看你的曲库、控制播放、改收藏。现在只放行两条路：

- 飞牛应用中心 / `NAS:5666` 入口（正常使用，功能不变）
- **DLNA 投播**（电视、音箱直接取流，UPnP 协议本身没有鉴权，封了就投不出声）

浏览器直接访问 `http://内网IP:端口` 会看到一张说明页。

## 五、界面细节

- **点过的按钮挂着灰框**：安卓/iOS 会把"悬停"状态留在最后点过的按钮上，全站六十多条悬停规则都补了触摸端还原。
- **数据维护面板**：三颗按钮改成"步骤 1 / 步骤 2 + 危险区"，因为清理和迁移本来就有先后顺序。
- **关于页显示版本号**：数字取自正在运行的服务端，升级后不会再显示旧版本。
- **安卓图标**：修掉自适应图标被圆形遮罩切边的问题；图标里的音符也缩小一圈，四个圆角不再挤在一起。

## 升级步骤

1. **服务端**：应用中心更新 `fnaudio-0.2.157-fnpack.fpk`
2. **手机**：覆盖安装 `fnaudio-android-0.2.157-release.apk`
3. **首次打开会重新扫描一次曲库**（标识规则变了），这次稍慢，之后正常
4. 打开 **设置 → 高级 → 数据维护**，按顺序点一次①清理失效收藏、②重建曲目标识并迁移收藏
5. 桌面图标没变的话，**重启手机**（启动器缓存不会自动刷新）

> 直连地址已经不可用，请从飞牛应用中心打开；投音到音箱/电视不受影响。

## 已知限制

- **WMA 只能转码播放**：浏览器与安卓都没有 WMA 解码器，这是平台限制。
- **直连端口不可用**：为安全关闭；DLNA 投播不受影响。
- **重装前丢失的收藏无法恢复**：旧标识是单向哈希。
