# fnAudio 更新说明：0.2.144 → 0.2.149

（`versionCode` 402 → 407）

## 一、手机端：FN ID 能登录了

- **填 FN ID 从公网登录现在可用。** 以前填域名能登、填 FN ID 报「HTTPS 证书校验失败」，是程序的问题，已修。
- 直连不通时，「速度优先」会**自动改用中继**，不用再手动切。
- 「公网连接」不通会直接提示你改用中继，不再报无关的证书错误。
- 同一 WiFi 下优先走内网地址。
- 令牌过期自动回退密码重登时不再闪退。
- 登录成功后曲库空、报「响应体不完整」的问题也已修复。

> 外网直连需要手机有 **IPv6**。想用 IPv4 直连，得在路由器上把 `5667` 映射到 NAS。

## 二、登录页少了一个勾选

「允许自签名证书」已去掉。现在证书一律接受，第一次连上记下指纹，**以后证书变了会自动拒绝**。

## 三、其他改动

- **播放设备**：改成后台扫描，点开就有列表，不用等它扫局域网。
- **音乐目录**：两个按钮合成一个「+ 添加目录」，能直接加局域网共享；多个目录的健康状态分别显示。
- **应用中心图标**：列表里不再显示灰底占位图。

## 四、两点说明

- **数播关机后打不开**：这版只是加固（放宽了启动等待时间），真实原因还没确认。再遇到请提供 `@appdata/info.log`。
- **电视端已暂停**，不再随版本发布。之前装的电视版不会被覆盖，需要卸载请自行操作。

## 五、升级注意

- **手机端**：覆盖安装即可，不需要重新登录。
- **服务端**：本区间无破坏性改动，可不升级。
